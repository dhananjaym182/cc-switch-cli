🔌 API ENDPOINTS (12 total)
═══════════════════════════════════════════════════════════════════════════════

Status:
  GET  /api/status

CC-Switch:
  GET  /api/ccswitch/providers?app={app}
  GET  /api/ccswitch/current?app={app}
  POST /api/ccswitch/switch
  GET  /api/ccswitch/config

Custom Tools:
  GET    /api/tools
  GET    /api/tools/:name
  GET    /api/tools/:name/status
  POST   /api/tools/register
  POST   /api/tools/:name/switch
  DELETE /api/tools/:name

Configuration:
  GET  /api/config

🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════════

1. Setup:
   ./start.sh

2. Start Backend (Terminal 1):
   cd backend && npm start
   → http://localhost:3010

3. Start Frontend (Terminal 2):
   cd frontend && npm run dev
   → http://localhost:3000

4. Open Browser:
   http://localhost:3000

🎯 DESIGN PRINCIPLES
═══════════════════════════════════════════════════════════════════════════════

✅ Simple, Local-First
   - File-based storage (no database)
   - Optional password auth (no OAuth)
   - Single-user focus
   - Localhost only

✅ Focused on API Switching
   - Not an API proxy
   - Not a request router
   - Just configuration management

✅ Extensible
   - Schema-driven tool registration
   - No hardcoded tools
   - Easy to add formats

✅ Developer-Friendly
   - Minimal dependencies
   - Clear code structure
   - Comprehensive docs
